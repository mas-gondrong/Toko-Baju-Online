# 👗 Toko Baju Online
Aplikasi toko baju berbasis web yang bisa diinstal seperti aplikasi asli, mendukung akses offline, dan terhubung dengan Firebase Realtime Database.

## ✨ Fitur
- ✅ Tampilan modern & responsif
- ✅ Bisa diinstal ke layar utama HP (PWA)
- ✅ Simpan data produk & gambar di Firebase
- ✅ Keranjang belanja
- ✅ Riwayat pesanan
- ✅ Login pengguna
- ✅ Bisa dibuka saat offline

## 🛠️ Teknologi
- HTML5 · CSS3 · JavaScript
- Firebase Realtime Database
- Firebase Authentication
- Progressive Web App (Service Worker + Manifest)

## 📦 Cara Pasang
1. Clone repositori ini
2. Buka `firebase-config.js`, masukkan konfigurasi Firebase kamu
3. Aktifkan Realtime Database & Authentication di Firebase Console
4. Buka `index.html` di browser atau jalankan di server lokal
